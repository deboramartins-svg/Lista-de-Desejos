# 🛒 Lista de Compras Feminina & Organização

Um aplicativo web prático e elegante desenvolvido para organizar listas de compras e o dia a dia no mercado, com um visual mais delicado e focado na facilidade de uso na hora de riscar os itens.

---

## 🚀 Demonstração Online

Acesse o projeto em funcionamento: [lista-de-desejos-sigma.vercel.app](https://lista-de-desejos-sigma.vercel.app)

---

## ✨ Principais Funcionalidades

* **Gerenciamento de Lista de Compras:** Adicione, organize e controle os itens necessários de forma rápida direto pelo celular enquanto faz compras.
* **Interface Delicada e Funcional:** Design limpo, intuitivo e com toque visual personalizado.
* **Design Responsivo:** Otimizado para uso ágil no smartphone nos corredores do supermercado.

---

## 🛠️ Tecnologias Utilizadas

* **Frontend:** JavaScript moderno / Framework baseado em componentes
* **Estilização:** CSS / Design responsivo personalizado
* **Deploy e Hospedagem:** Vercel
